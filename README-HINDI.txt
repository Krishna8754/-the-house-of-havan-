THE HOUSE OF HAVAN — WEBSITE STARTER

इस ZIP में:
- index.html : वेबसाइट का कंटेंट
- style.css  : Luxury design और mobile responsive layout
- script.js  : WhatsApp booking बटन और mobile menu

सबसे जरूरी बदलाव:
1. script.js खोलें।
2. WHATSAPP_NUMBER में 91XXXXXXXXXX की जगह होटल का WhatsApp नंबर लिखें।
   उदाहरण: 919876543210 (भारत का country code 91; +, space या dash न लगाएँ)
3. index.html में sample gallery photos को होटल की असली photos से बदलें।
4. होटल का पूरा पता, फोन नंबर, room types, सुविधाएँ और check-in/check-out जानकारी मिलने पर वेबसाइट में जोड़ें।

अपने कंप्यूटर पर देखने के लिए:
- ZIP extract करें।
- index.html पर double-click करें।
- वेबसाइट browser में खुल जाएगी।

ऑनलाइन प्रकाशित करने के लिए:
GitHub पर नया public repository बनाकर इन तीनों फाइलों को upload करें।
Repository में Settings > Pages > Deploy from a branch > main > /(root) चुनें।
कुछ मिनट बाद GitHub Pages वेबसाइट का URL देगा।

नोट:
- अभी होटल का पूरा street address, WhatsApp नंबर, वास्तविक room photos, room rates और सुविधाएँ उपलब्ध नहीं हैं।
- इसलिए वेबसाइट में कोई कीमत या अपुष्ट सुविधा नहीं लिखी गई है।
- फोटो इंटरनेट से sample हैं; इन्हें होटल की वास्तविक तस्वीरों से बदलना बेहतर होगा।
